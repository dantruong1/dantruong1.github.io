| Role     | Font Family       | Weight | Usage                        |
|----------|-------------------|--------|------------------------------|
| Display  | Fraunces          | 300–700 | Page titles, card headers   |
| Body     | Inter             | 300–600 | Body text, descriptions     |
| Handwritten | Caveat         | 400–700 | Section labels, greetings   |
| Mono     | Space Mono        | 400    | Badges, attributions, dates |

## Design Principles

1. **Light & Warm**: Cream/parchment backgrounds, NOT dark mode
2. **Bento Grid Hero**: Asymmetric 2-column grid with photo + intro + accent
3. **Rounded Corners**: `1.25rem–1.75rem` radius on all cards
4. **Soft Shadows**: Subtle warm-toned box-shadows
5. **Sage Green Accents**: Primary interactive color
6. **Handwritten Touches**: Caveat font for section labels and greetings
7. **Organic Feel**: Generous whitespace, soft borders, hover lift effects
8. **No Dark Background**: This is intentionally a light, airy, cafe-inspired site

## External Dependencies

- **Google Fonts**: Fraunces, Inter, Caveat, Space Mono
- **Phosphor Icons**: `@phosphor-icons/web` via unpkg CDN
- **No other libraries needed** — pure vanilla HTML/CSS/JS
